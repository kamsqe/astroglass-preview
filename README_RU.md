# Astro Glass Cloudflare Starter

Современный стартовый набор, созданный на [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com) и [Fuse.js](https://fusejs.io) для поиска. Легко развертывается на Cloudflare Pages.

## 🚀 Основные возможности

- **Astro 5.0**: Быстрая генерация статических сайтов.
- **Tailwind CSS**: Утилитарная стилизация с кастомной дизайн-системой.
- **Интернационализация (i18n)**: Нативная поддержка английского (`en`) и русского (`ru`) языков.
- **Поиск на Fuse.js**: Клиентский нечеткий поиск с кастомной индексацией, подсветкой и мобильной оптимизацией.
- **Адаптивный UI**: Глассморфизм дизайн, навигация через боковое меню (drawer) на мобильных и плавные анимации.
- **Готовность к Cloudflare**: Настроен для развертывания на edge.

## 🛠️ Команды

Все команды запускаются из корня проекта:

| Команда                   | Действие                                         |
| :------------------------ | :----------------------------------------------- |
| `pnpm install`            | Устанавливает зависимости                        |
| `pnpm dev`                | Запускает локальный сервер на `localhost:4321`   |
| `pnpm build`              | Собирает продакшн-версию в папку `./dist/`       |
| `pnpm preview`            | Предпросмотр сборки локально                     |
| `pnpm astro ...`          | Запуск CLI команд, например `astro add`          |

## 🔍 Реализация поиска

Этот проект заменяет стандартную интеграцию Pagefind на **Fuse.js**, чтобы обеспечить полностью кастомизируемый поиск с ощущением "премиум" качества.

### Архитектура

1.  **Индексация**:
    *   Скрипт `scripts/generate-search-index.mjs` запускается во время сборки (`build`).
    *   Он сканирует весь контент (файлы MDX) и генерирует JSON-индексы для каждого языка:
        *   `public/search/en.json`
        *   `public/search/ru.json`

2.  **Фронтенд (`CommandPalette.astro`)**:
    *   Загружает соответствующий JSON-индекс в зависимости от текущего языка.
    *   Использует **Fuse.js** для нечеткого поиска (поддерживает опечатки).
    *   Возможности:
        *   **Недавние поиски**: Сохраняются в `localStorage`.
        *   **Быстрые ссылки**: Мгновенный доступ к ключевым страницам.
        *   **"Возможно, вы имели в виду?"**: Предлагает страницы, если ничего не найдено.
        *   **Клавиатурная навигация**: Полная поддержка стрелок, `Cmd+K`, `/`, `Enter`.
    
3.  **UI/UX**:
    *   **Подсветка**: Использует кастомную анимацию "мерцающий контур" (outline shimmer), которая не сдвигает верстку.
    *   **Мобильные устройства**: Оптимизированные области нажатия, жест закрытия свайпом и чистая панель навигации.
    *   **Визуал**: Премиум карточки с эффектом глассморфизма и SVG иконками.

### Настройка

Вы можете изменить поведение поиска в файле `src/components/docs/CommandPalette.astro`:

- **Веса (Weights)**: Приоритет полей (Заголовок > Подзаголовки > Контент).
- **Порог (Threshold)**: Настройка нечеткости (0.0 = точное совпадение, 1.0 = совпадение с чем угодно).
- **Стилизация**: Все стили изолированы и используют CSS переменные для темизации.

## 📂 Структура проекта

```text
/
├── public/
│   └── search/        # Сгенерированные поисковые индексы
├── scripts/
│   └── generate-search-index.mjs
├── src/
│   ├── components/    # UI Компоненты (Docs, Search и др.)
│   ├── content/       # Коллекции контента (Docs, Blog)
│   ├── layouts/       # Шаблоны страниц
│   ├── locales/       # Строки переводов i18n
│   ├── pages/         # Файловый роутинг
│   └── utils/         # Вспомогательные функции (i18n, навигация)
└── package.json
```

## 🌍 Интернационализация

- **Контент**: Размещайте локализованный контент в `src/content/docs/{locale}/`.
- **Строки UI**: Управляйте переводами в `src/locales/{locale}/*.json`.
- **Роутинг**: Роутинг на основе URL (например, `/en/docs`, `/ru/docs`).
