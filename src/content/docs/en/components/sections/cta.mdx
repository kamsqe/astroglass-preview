## Best Practices

1.  **Clear Value**: State exactly what they get.
2.  **Urgency**: Use words like "Today" or "Now".
3.  **Contrast**: Ensure the button stands out against the background.

## Variants

- `CTAV1`: Simple centered text + button
- `CTAV2`: Split layout with image
- `CTAV3`: Floating glass card
- `CTAV4`: Magnetic attraction effect (Interactive)
- `CTAV5`: Terminal style (Developer focused)
