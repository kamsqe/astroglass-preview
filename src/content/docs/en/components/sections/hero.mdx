## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | - | Main headline |
| `subtitle` | `string` | - | Subtext below headline |
| `image` | `ImageMetadata` | - | Hero image (if applicable) |
| `primaryCta` | `string` | "Get Started" | Primary button text |

## Usage

```astro title="Component.astro"
---
---

<HeroV1 
  title="Build Faster"
  subtitle="The ultimate Astro theme."
/>
```
