Liquid Glass provides a set of "Wrapper Components" for major page sections. These components automatically handle theme switching based on the `version` prop.

Each component supports 5 distinct design themes:
1. **Liquid** (Default)
2. **Glass**
3. **Neo**
4. **Luxury**
5. **Minimal**

## Hero

The Hero component is the entry point of your landing page.

```astro
import Hero from '../../components/sections/hero/index.astro';

<Hero version={1} /> <!-- Liquid Theme -->
<Hero version={2} /> <!-- Glass Theme -->
```

## Features

Display your product features in a grid or list layout.

```astro
import Features from '../../components/sections/features/index.astro';

<Features version={3} /> <!-- Neo Theme -->
```

## Pricing

import Pricing from '../../components/sections/pricing/index.astro';

## How It Works

Under the hood, these wrapper components dynamically import the specific implementation based on the version prop.

For example, `<Hero version={1} />` renders `src/components/sections/hero/HeroLiquid.astro`.

<Callout type="tip" title="Customization">
  To customize a specific section, you should edit the file in the subdirectory (e.g., `src/components/sections/hero/HeroGlass.astro`) rather than the wrapper component itself.
</Callout>
