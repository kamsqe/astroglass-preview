## Variants

| Component | Style |
| :--- | :--- |
| `TestimonialV1` | Single highlighted quote |
| `TestimonialV2` | 3-Column Grid |
| `TestimonialV3` | Masonry Grid (Wall of Love) |
| `TestimonialV4` | Slider / Carousel |

## Tips

Use `TestimonialV1` for high-impact landing pages, and `TestimonialV3` for a dedicated reviews page.
