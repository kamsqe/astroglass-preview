Liquid Glass uses **Tailwind CSS v4** for styling, which offers better performance and a streamlined configuration experience.

## Styling Overview

Global styles and CSS variables are defined in `src/styles/global.css`. This file handles:
- Base layer resets
- Custom fonts (Inter & JetBrains Mono)
- CSS variables for theming (HSL color values)

<FileTree>
- src/
  - styles/
    - **global.css**
- **tailwind.config.mjs**
</FileTree>

## Theming System

The project uses a CSS variable-based theming system. Colors are defined as HSL values (without the `hsl()`) function, allowing Tailwind's opacity modifier to work correctly.

```css title="styles.css"
/* src/styles/global.css */
:root {
  /* HSL values */
  --p: 260 80% 60%; /* Primary */
  --s: 310 80% 60%; /* Secondary */
  --a: 190 90% 60%; /* Accent */
  
  --b1: 220 20% 10%; /* Base 1 (Background) */
  --bc: 220 20% 90%; /* Base Content (Text) */
}
```

Components consume these variables via Tailwind utility classes or custom `hsl()` usage.

```html title="index.html"
<div class="bg-[hsl(var(--p))] text-[hsl(var(--bc))]">
  Primary Background with Base Content Text
</div>
```

<Callout type="tip" title="Changing Colors">
  To change the site's color scheme, update the HSL values in `src/styles/global.css`. You can define different values for light/dark mode using the `[data-theme="light"]` selector if needed.
</Callout>

## Tailwind Configuration

Tailwind v4 is configured in `src/styles/global.css` using the `@theme` directive, but for backward compatibility or complex plugins, we also include a `tailwind.config.mjs` file.

You can extend the theme, add plugins, or modify content paths in `tailwind.config.mjs`.

```javascript
/* tailwind.config.mjs */
/** @type {import('tailwindcss').Config} */
export default {
  content: ['./src/**/*.{astro,html,js,jsx,md,mdx,svelte,ts,tsx,vue}'],
  theme: {
    extend: {
      fontFamily: {
        sans: ['Inter Variable', 'sans-serif'],
        mono: ['JetBrains Mono Variable', 'monospace'],
      },
      // ...
    },
  },
  plugins: [],
}
```

## Adding Custom Fonts

1.  Place font files in `public/fonts/` or import from Google Fonts.
2.  Define the font-face in `src/styles/global.css`.
3.  Update the font family in `tailwind.config.mjs`.

## Component Customization

Most UI components expose props for basic customization (like `version` for Wrapper Components). For deeper changes, you should modify the component files directly in `src/components/`.

For example, to change the layout of the Header, edit `src/components/layout/DesktopNav.astro` and `src/components/layout/MobileNav.astro`.
