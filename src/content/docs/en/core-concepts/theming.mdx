Our template features a highly flexible dynamic theming system built on top of **Tailwind CSS** and **Astro's component architecture**.

## Architecture Overview

The theming system consists of three main layers:

1. **Theme Registry**: Definitions for each theme in `src/config/themes.ts`.
2. **CSS Custom Properties**: Theme-aware variables defined in `src/styles/_themes.css`.
3. **Dynamic Rendering**: Section components that render variants based on the `version` prop.

## Theme Registry

Every theme must be registered in the `themes.ts` file. This centralizes theme metadata and makes it available to the entire application.

<FileTree>
- src/
  - config/
    - themes.ts [modified]
</FileTree>

Each theme definition looks like this:

```typescript
export const themes: ThemeDefinition[] = [
  {
    id: 'liquid',
    name: 'Liquid',
    color: 'bg-indigo-600',
    icon: '💧',
    sections: ['Hero', 'About', 'Pricing'],
    enabled: true,
    premium: false
  },
  // ... other themes
];
```

## CSS Variables

We use standard CSS variables (custom properties) to handle theme-specific colors and effects. These variables are scoped to a data attribute on the `<html>` or `<body>` tag.

<CodeTabs labels={['CSS', 'Tailwind']}>
```css
/* src/styles/_themes.css */
[data-theme="liquid"] {
  --color-primary: 79 70 229;
  --color-accent: 124 58 237;
  --glass-blur: 8px;
}
```
```html
<!-- usage in component -->
<div class="bg-primary/10 border-accent/20 backdrop-blur-[var(--glass-blur)]">
  Themed Content
</div>
```
</CodeTabs>

<Callout type="warning" title="Naming Convention">
  Always use the `--color-*` prefix for theme variables to ensure consistency with our utility classes.
</Callout>

## Dynamic Component Loading

Section components like `Hero.astro` act as wrappers. They dynamically import the correct theme variant based on the `version` prop.

```astro
---
// src/components/sections/hero
const { version } = Astro.props;

// Logic to load HeroLiquid, HeroGlass, etc.
const ThemeComponent = themeMap[version] || HeroLiquid;
---

<ThemeComponent { ...Astro.props } />
```

<Callout type="info">
  This pattern allows for maximum flexibility. You can have completely different HTML structures for different themes while keeping a uniform API for the page templates.
</Callout>

## Creating a New Theme

To add a new theme, follow these steps:

1. Add the theme definition to `src/config/themes.ts`.
2. Define the new theme's CSS variables in `src/styles/_themes.css`.
3. (Optional) Create theme-specific components in `src/components/sections/hero/`, etc.
4. Add any new localized strings to the translation files.
