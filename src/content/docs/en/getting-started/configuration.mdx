AstroGlass is configured via files in `src/config/` and standard CSS custom properties.

## Interactive CLI Configurator

The fastest way to configure your project is the interactive CLI:

```bash frame="terminal"
pnpm configure
```

It lets you:

- **Pick a theme** — one of 6 (Liquid, Glass, Neo, Luxury, Minimal, Aurora)
- **Pick languages** — any combination of 7 supported languages
- **Pick color palettes** — any combination of 10 built-in palettes

The CLI then prunes all unused themes, locale files, and palette CSS from the project. If you select a single language or palette, it also removes the corresponding switcher component from the navbar.

<Callout type="warning" title="Run once on a fresh clone">
  The configurator permanently deletes unused files. Run it once after cloning, before you start
  customizing content.
</Callout>

## Configuration Files

<FileTree>
  - src/ - config/ - **themes.ts** — Theme definitions (name, colors, sections, premium flag) -

## Styling with Tailwind CSS v4

This project uses **Tailwind CSS v4** via the `@tailwindcss/vite` plugin. There is no `tailwind.config.mjs` file — all configuration is done through CSS.

Colors and theme variables are defined as CSS custom properties in `src/styles/global.css` and `src/styles/_themes.css`:

```css title="global.css"
:root {
  --p: 260 80% 60%; /* Primary (HSL) */
  --s: 310 80% 60%; /* Secondary */
  --a: 190 90% 60%; /* Accent */
  --b1: 220 20% 10%; /* Base background */
  --bc: 220 20% 90%; /* Base content (text) */
}
```

<Callout type="tip" title="Changing Colors">
  To change the site's color scheme, update the HSL values in `src/styles/global.css`.
  Theme-specific overrides live in `src/styles/_themes.css` using `[data-theme="..."]` selectors.
  Each palette has its own CSS file in `src/styles/palettes/`.
</Callout>

## Theme Configuration

Each theme is registered in `src/config/themes.ts`. This centralizes all theme metadata:

```typescript title="themes.ts"
export const themes: ThemeDefinition[] = [
  {
    id: 'liquid',
    name: 'Liquid',
    color: 'from-blue-500 to-cyan-400',
    icon: '💧',
    sections: [
      'Header',
      'Hero',
      'About',
      'Features',
      'Portfolio',
      'Pricing',
      'Testimonial',
      'FAQ',
      'CTA',
      'Contact',
      'Footer',
    ],
    enabled: true,
    premium: false,
    description: 'Fluid, organic design with smooth animations',
  },
  // ... 5 more themes (Glass, Neo, Luxury, Minimal, Aurora)
];
```

## Locale Configuration

Languages are managed in `src/config/locales.ts`. To add a new language, add an entry and set `enabled: true`:

```typescript title="locales.ts"
export const localesConfig: LocaleConfig[] = [
  {
    code: 'en',
    name: 'English',
    nativeName: 'English',
    flag: '🇬🇧',
    direction: 'ltr',
    enabled: true,
  },
  {
    code: 'ru',
    name: 'Russian',
    nativeName: 'Русский',
    flag: '🇷🇺',
    direction: 'ltr',
    enabled: true,
  },
];
```

## Palette Configuration

Color palettes are defined in `src/config/palettes.ts` and each palette's CSS lives in `src/styles/palettes/`:

| Category     | Palettes                              |
| ------------ | ------------------------------------- |
| **Light**    | Azure, Nordic, Solaris                |
| **Dark**     | Abyss, Neonoir, Synthwave             |
| **Colorful** | Evergreen, Rose, Aquatica, Monochrome |

Switch palettes at runtime by setting the `data-theme` attribute on `<html>`.
