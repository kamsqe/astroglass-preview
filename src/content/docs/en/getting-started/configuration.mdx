# Configuration

The theme is configured via `src/config/site.ts` (coming soon) and standard Astro configuration files.

## Tailwind Config

You can customize the colors and fonts in `tailwind.config.mjs` or by editing the CSS variables in `src/styles/global.css`.

```css title="styles.css"
:root {
  --color-accent: 210 100% 50%; /* Blue */
  --glass-opacity: 0.7;
}
```
