Getting started is easy. You can clone the repository or use the CLI.

## Prerequisites

- Node.js v18.0.0 or higher
- pnpm (recommended) or npm/yarn

## Quick Start

<Steps>
1. **Clone the repository**
   
   ```bash frame="terminal"
   git clone https://github.com/mirmanoov/liquid-glass-astro.git my-project
   ```

2. **Enter the directory**

   ```bash frame="terminal"
   cd my-project
   ```

3. **Install dependencies**

   ```bash frame="terminal"
   pnpm install
   ```

4. **Start development server**

   ```bash frame="terminal"
   pnpm dev
   ```
</Steps>

Visit `http://localhost:4321` to see your new site.
