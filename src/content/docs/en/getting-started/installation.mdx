Getting started is easy. Clone the repository, install dependencies, and run the interactive configurator.

## Prerequisites

- Node.js v22.12.0 or higher
- pnpm v8+ (recommended) or npm/yarn

## Quick Start

<Steps>
1. **Clone the repository**

   ```bash frame="terminal"
   git clone https://github.com/kamsqe/astroglass.git my-project
   ```

2. **Enter the directory**

   ```bash frame="terminal"
   cd my-project
   ```

3. **Install dependencies**

   ```bash frame="terminal"
   pnpm install
   ```

4. **Run the configurator**

   ```bash frame="terminal"
   pnpm configure
   ```

   The interactive CLI walks you through selecting your theme, languages, and color palettes. It then removes all unused code, keeping your project lean.

5. **Start development server**

   ```bash frame="terminal"
   pnpm dev
   ```

</Steps>

Visit `http://localhost:4321` to see your new site.

<Callout type="tip" title="Skipping the configurator">
  You can skip `pnpm configure` and keep all 6 themes, 7 languages, and 10 palettes. The configurator is optional — it just prunes what you don't need.
</Callout>
