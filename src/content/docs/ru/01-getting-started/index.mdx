Добро пожаловать в шаблон **Liquid Glass**! Это руководство поможет вам настроить среду разработки и адаптировать шаблон под ваши нужды.

## Предварительные требования

Прежде чем начать, убедитесь, что у вас установлено следующее:

- **Node.js** версии 18 или выше
- **pnpm** (рекомендуется) или npm
- Редактор кода (рекомендуется VS Code)

<Callout type="tip" title="Совет">
  Мы рекомендуем использовать [pnpm](https://pnpm.io/) для быстрой и эффективной работы с пакетами.
</Callout>

## Установка

<Steps>

### Клонируйте репозиторий

Сначала клонируйте репозиторий шаблона на свой локальный компьютер:

```bash
git clone https://github.com/your-username/liquid-glass-astro-cloudflare.git
cd liquid-glass-astro-cloudflare
```

### Установите зависимости

Установите зависимости проекта, используя ваш любимый менеджер пакетов:

<CodeTabs labels={['pnpm', 'npm', 'yarn']}>
```bash
pnpm install
```
```bash
npm install
```
```bash
yarn install
```
</CodeTabs>

### Запустите сервер разработки

Запустите сервер разработки, чтобы увидеть шаблон в действии:

<CodeTabs labels={['pnpm', 'npm', 'yarn']}>
```bash
pnpm dev
```
```bash
npm run dev
```
```bash
yarn dev
```
</CodeTabs>

</Steps>

Ваш сайт теперь должен быть доступен по адресу `http://localhost:4321` 🎉

## Выбор темы

Шаблон поставляется с **5 великолепными темами**:

| Тема | Описание |
|-------|-------------|
| **Liquid** | Плавные анимации, градиентные фоны |
| **Glass** | Эффекты стекломорфизма, полупрозрачные панели |
| **Neo** | Смелая типографика, сильный контраст |
| **Luxury** | Элегантные золотые акценты, премиальный вид |
| **Minimal** | Чистый, сфокусированный дизайн без лишних деталей |

Чтобы переключить тему, просто воспользуйтесь переключателем в шапке сайта или посетите демонстрационные страницы тем напрямую.
