# Компоненты Функций

Продемонстрируйте возможности вашего продукта с помощью наших универсальных секций.

## Компоненты

Мы предоставляем 5 вариантов для разной плотности контента.

| Компонент | Стиль | Для чего лучше |
| :--- | :--- | :--- |
| `FeaturesV1` | Сетка из 3 колонок | Общий обзор множества функций |
| `FeaturesV2` | Чередование (Zig-Zag) | Детальный разбор с изображениями |
| `FeaturesV3` | Сетка Bento | Современные асимметричные макеты |
| `FeaturesV4` | Список с иконками | Технические характеристики |
| `FeaturesV5` | Табы / Аккордеон | Группировка сложных функций |
