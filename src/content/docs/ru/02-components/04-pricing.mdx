# Таблицы Цен

Превращайте посетителей в клиентов с помощью понятных тарифных планов.

## Свойства

| Свойство | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `plans` | `Plan[]` | - | Массив тарифных уровней |
| `currency` | `string` | "$" | Символ валюты |
| `period` | `string` | "month" | Период оплаты |
