Этот справочник документирует публичный API для всех компонентов шаблона. Каждый компонент полностью типизирован с помощью TypeScript и поддерживает интернационализацию из коробки.

## Компонент Hero

Компонент `Hero` отображает основной раздел сайта с поддержкой динамических тем.

<ApiMethod
  name="Hero"
  signature="<Hero version={string} locale={Locale} />"
  description="Отрисовывает тематический раздел hero с заголовком, подзаголовком и кнопками призыва к действию."
  params={[
    { name: 'version', type: 'ThemeId', description: 'Идентификатор темы для рендеринга', required: true },
    { name: 'locale', type: 'Locale', description: 'Текущая локаль для i18n', required: false, default: '"en"' }
  ]}
  returns={{ type: 'AstroComponent', description: 'Отрисованный раздел hero' }}
  since="v1.0.0"
/>

### Использование

```astro
---
---

<Hero version="glass" locale="ru" />
```

### Доступные версии

| Версия | Описание |
|---------|-------------|
| `liquid` | Жидкие градиентные анимации |
| `glass` | Стекломорфизм с эффектами размытия |
| `neo` | Смелый, высококонтрастный дизайн |
| `luxury` | Золотые акценты, премиальный стиль |
| `minimal` | Чистый, сфокусированный макет |

## useTranslations <Badge type="new">v1.1</Badge>

Функция `useTranslations` возвращает функцию перевода для указанной локали.

<ApiMethod
  name="useTranslations"
  signature="useTranslations(locale: Locale): (key: string, params?: Record<string, string>) => string"
  description="Возвращает функцию перевода, которая извлекает локализованные строки по пути ключа."
  params={[
    { name: 'locale', type: 'Locale', description: 'Целевой код локали (например, "en", "ru")', required: true }
  ]}
  returns={{ type: '(key: string) => string', description: 'Функция перевода' }}
  since="v1.0.0"
/>

### Использование

```typescript

const t = useTranslations('ru');

const title = t('hero.title');           // "Добро пожаловать"
const cta = t('hero.primaryCta');         // "Начать"
```

### Вложенные ключи

Ключи перевода поддерживают точечную нотацию для вложенных значений:

```typescript
const t = useTranslations('ru');

t('pricing.plans.pro.name');  // "Профессиональный"
t('pricing.plans.pro.price'); // "1999"
```

## ThemeDefinition <Badge>Type</Badge>

Интерфейс TypeScript для объектов конфигурации темы.

```typescript
interface ThemeDefinition {
  id: string;          // Уникальный идентификатор темы
  name: string;        // Отображаемое имя
  color: string;       // Основной цвет (класс Tailwind)
  icon: string;        // Иконка emoji
  sections: string[];  // Доступные компоненты разделов
  enabled: boolean;    // Включена ли тема
  premium: boolean;    // Флаг только для премиум-доступа
}
```
