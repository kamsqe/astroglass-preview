# Глассморфизм

Liquid Glass реализует современный подход к глассморфизму.

## Рецепт

1.  **Размытие фона**: Мы используем `backdrop-filter: blur(12px)` для эффекта матового стекла.
2.  **Полупрозрачность**: Фоновые цвета используют альфа-каналы (например, `bg-white/10`).
3.  **Границы**: Тонкие границы в 1px (`border-white/20`) определяют края.
4.  **Тени**: Мягкие цветные тени создают глубину.

Эта комбинация создает ощущение иерархии и современности.
