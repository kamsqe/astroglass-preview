Наш шаблон обладает гибкой системой динамических тем, построенной на основе **Tailwind CSS** и компонентной архитектуры **Astro**.

## Обзор архитектуры

Система тем состоит из трех основных уровней:

1. **Реестр тем**: Определения для каждой темы в файле `src/config/themes.ts`.
2. **Пользовательские свойства CSS**: Переменные, зависящие от темы, определенные в `src/styles/_themes.css`.
3. **Динамический рендеринг**: Компоненты разделов, которые отрисовывают варианты в зависимости от пропса `version`.

## Реестр тем

Каждая тема должна быть зарегистрирована в файле `themes.ts`. Это централизует метаданные темы и делает их доступными для всего приложения.

<FileTree>
- src/
  - config/
    - themes.ts [изменен]
</FileTree>

Каждое определение темы выглядит следующим образом:

```typescript
export const themes: ThemeDefinition[] = [
  {
    id: 'liquid',
    name: 'Liquid',
    color: 'bg-indigo-600',
    icon: '💧',
    sections: ['Hero', 'About', 'Pricing'],
    enabled: true,
    premium: false
  },
  // ... другие темы
];
```

## Переменные CSS

Мы используем стандартные переменные CSS для управления цветами и эффектами, специфичными для темы. Эти переменные привязаны к соответствующему атрибуту `data-theme` на теге `<html>` или `<body>`.

<CodeTabs labels={['CSS', 'Tailwind']}>
```css
/* src/styles/_themes.css */
[data-theme="liquid"] {
  --color-primary: 79 70 229;
  --color-accent: 124 58 237;
  --glass-blur: 8px;
}
```
```html
<!-- использование в компоненте -->
<div class="bg-primary/10 border-accent/20 backdrop-blur-[var(--glass-blur)]">
  Тематический контент
</div>
```
</CodeTabs>

<Callout type="warning" title="Соглашение об именовании">
  Всегда используйте префикс `--color-*` для переменных темы, чтобы обеспечить совместимость с нашими утилитными классами.
</Callout>

## Динамическая загрузка компонентов

Компоненты разделов, такие как `Hero.astro`, действуют как обертки. Они динамически импортируют правильный вариант темы на основе пропса `version`.

```astro
---
// src/components/Hero.astro
const { version } = Astro.props;

// Логика загрузки HeroLiquid, HeroGlass и т.д.
const ThemeComponent = themeMap[version] || HeroLiquid;
---

<ThemeComponent { ...Astro.props } />
```

<Callout type="info">
  Этот паттерн обеспечивает максимальную гибкость. Вы можете иметь совершенно разные структуры HTML для разных тем, сохраняя при этом единообразный API для шаблонов страниц.
</Callout>

## Создание новой темы

Чтобы добавить новую тему, выполните следующие действия:

1. Добавьте определение темы в `src/config/themes.ts`.
2. Определите переменные CSS для новой темы в `src/styles/_themes.css`.
3. (Опционально) Создайте специфичные для темы компоненты в `src/components/hero/` и т.д.
4. Добавьте новые локализованные строки в файлы переводов.
