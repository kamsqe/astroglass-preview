## Варианты

- `CTAV1`: Простой центрированный текст + кнопка
- `CTAV2`: Разделенный макет с изображением
- `CTAV3`: Парящая стеклянная карточка
- `CTAV4`: Эффект магнитного притяжения (Интерактивный)
- `CTAV5`: Стиль терминала (Для разработчиков)
