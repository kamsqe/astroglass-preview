## Пропсы

| Prop | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `title` | `string` | - | Основной заголовок |
| `subtitle` | `string` | - | Подзаголовок |
| `image` | `ImageMetadata` | - | Изображение hero (если применимо) |
| `primaryCta` | `string` | "Начать" | Текст основной кнопки |

## Использование

```astro title="Component.astro"
---
---

<HeroV1 
  title="Создавайте быстрее"
  subtitle="Лучшая тема для Astro."
/>
```
