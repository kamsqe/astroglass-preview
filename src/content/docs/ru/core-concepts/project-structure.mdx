## Ключевые директории

### `src/components`

Содержит все переиспользуемые UI компоненты. Компоненты верхнего уровня (например, `Hero.astro`) являются обертками, которые переключают различные реализации дизайна, расположенные в поддиректориях (например, `hero/HeroLiquid.astro`).

### `src/content`

Содержит Markdown и MDX контент для документации. Структура внутри `docs/[lang]` определяет структуру URL вашего сайта документации.

### `src/pages`

Файловый роутинг. Динамический параметр `[lang]` обрабатывает интернационализацию для всех основных страниц.

### `src/utils`

Утилитарные функции, в основном для обработки логики i18n переводов и навигации.
