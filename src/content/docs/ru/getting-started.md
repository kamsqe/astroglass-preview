# Начало работы

Добро пожаловать в стартовый набор **Liquid Glass**. Этот шаблон создан для высокопроизводительных сайтов документации и маркетинга, используя Astro 5.0 и Tailwind CSS.

## Основные возможности

- **Поиск на Fuse.js**: Клиентский нечеткий поиск с кастомной индексацией (заменил Pagefind).
- **Интернационализация**: Нативная поддержка i18n для английского (`en`) и русского (`ru`) языков.
- **Глассморфизм UI**: Премиальный визуальный стиль с backdrop-фильтрами и плавными анимациями.
- **Mobile First**: Оптимизированная навигация (drawer) и удобные взаимодействия на мобильных.

## Архитектура поиска

Система поиска использует **Fuse.js** для настраиваемого, "премиального" опыта.
- **Генерация индекса**: Запустите `pnpm build`, чтобы создать `public/search/{locale}.json`.
- **Фронтенд**: Компонент `CommandPalette` загружает индекс и обрабатывает нечеткое совпадение.
- **Настройка**: Настройте веса и пороги в `src/components/docs/CommandPalette.astro`.

## Быстрый старт

1.  **Установка зависимостей**:
    ```bash
    pnpm install
    ```
2.  **Запуск сервера разработки**:
    ```bash
    pnpm dev
    ```
3.  **Сборка для продакшена**:
    ```bash
    pnpm build
    ```
