# Конфигурация

Тема настраивается через `src/config/site.ts` (скоро появится) и стандартные файлы конфигурации Astro.

## Конфигурация Tailwind

Вы можете настроить цвета и шрифты в `tailwind.config.mjs` или отредактировав CSS-переменные в `src/styles/global.css`.

```css title="styles.css"
:root {
  --color-accent: 210 100% 50%; /* Blue */
  --glass-opacity: 0.7;
}
```
