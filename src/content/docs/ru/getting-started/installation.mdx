Начать работу легко. Вы можете клонировать репозиторий или использовать CLI.

## Предварительные требования

- Node.js v18.0.0 или выше
- pnpm (рекомендуется) или npm/yarn

## Быстрый старт

<Steps>
1. **Клонировать репозиторий**
   
   ```bash frame="terminal"
   git clone https://github.com/mirmanoov/liquid-glass-astro.git my-project
   ```

2. **Перейдите в директорию**

   ```bash frame="terminal"
   cd my-project
   ```

3. **Установите зависимости**

   ```bash frame="terminal"
   pnpm install
   ```

4. **Запустите сервер разработки**

   ```bash frame="terminal"
   pnpm dev
   ```
</Steps>

Перейдите на `http://localhost:4321`, чтобы увидеть ваш новый сайт.
